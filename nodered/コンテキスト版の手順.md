## 自分で作り始めるとき

1. 完成品の6つのタブをすべて無効にし、デプロイする（タブ名をダブルクリック →「無効」にする）。自作のフローと URL（`/app`、`/api/...`）が重なると、どちらが応答するか分からなくなるため。
2. 右上メニュー →「読み込み」で `flows_screen.json`（画面タブだけ）を読み込む。HTML はこれを使う。
3. 「コンテキスト版の方針.md」を見ながら、データ準備、参照API、登録API、出庫を作る。
4. グローバルコンテキストのキーは、完成品と同じ `degimono` にするとデータを引き継げる。分けたいときは別の名前にする。
5. 詰まったら、完成品のタブを開いて見比べる。共通処理は「共通処理（コンテキスト版）」タブにある。

完成品に戻すときは、自作のタブを無効にして完成品のタブを有効に戻す。

## 完成品を作り直す・入れ直す

画面（`../index.html`、`../m5_dummy.html`）やフローを直したら、このフォルダで次を実行する。

```bash
node make_flows_context.js   # flows_context.json ができる
```

ラズパイへの入れ方は2通り。

- エディタから: 右上メニュー →「読み込み」で `flows_context.json` を選ぶ。同じノードがあると聞かれるので「置換」を選び、デプロイする。
- コマンドで（既存のタブを残し、ID が `dc` で始まるノードだけを入れ替える）:
  ```bash
  scp flows_context.json raspi@192.168.50.2:/tmp/
  ssh raspi@192.168.50.2 'python3 - <<EOF
  import json, urllib.request
  base = "http://localhost:1880/flows"
  h = {"Node-RED-API-Version": "v2"}
  cur = json.load(urllib.request.urlopen(urllib.request.Request(base, headers=h)))
  new = json.load(open("/tmp/flows_context.json"))
  keep = [n for n in cur["flows"] if not n["id"].startswith("dc")]
  body = json.dumps({"rev": cur["rev"], "flows": keep + new}).encode()
  h.update({"Content-Type": "application/json", "Node-RED-Deployment-Type": "flows"})
  print(urllib.request.urlopen(urllib.request.Request(base, data=body, method="POST", headers=h)).read().decode())
  EOF'
  ```

## MQTT で試す

M5 がなくても、ブローカーのコンテナで送信と受信ができる。ターミナルを2つ使う。

```bash
# 1つ目: 結果を待つ
ssh raspi@192.168.50.2 "docker exec degimono-mqtt mosquitto_sub -t 'degimono/status' -v"

# 2つ目: 出庫を投げる
ssh raspi@192.168.50.2 "docker exec degimono-mqtt mosquitto_pub -t degimono/checkout -m '{\"part_id\":\"GH-4060\",\"quantity\":1,\"employee_id\":\"1001\"}'"
```

発注点以下の通知は `degimono/alert` に届く。M5 ダミー画面（`/m5-dummy`）は WebSocket（`/ws/alert`）で同じ通知を受けて画面に出す。待つときは 1つ目のトピックを `degimono/alert` にする（`-t '#'` にすると全部見られる）。

`../m5stickc_mqtt_sample.ino` は、ボタンAで `degimono/checkout` に出庫（社員名 `user_name` 付き）を送り、`degimono/alert` を購読して通知の `text` を画面に出すサンプル（M5Unified、日本語フォント efontJA_12）。

## Flask（本体）を動かし直すとき

```bash
ssh raspi@192.168.50.2 "cd ~/degimono && docker compose start web"
```

そのときは、Node-RED の「出庫（コンテキスト版）」タブの mqtt in を無効にする（両方で在庫が減るのを防ぐため）。止めたままにするなら、`docker compose up -d` を実行すると web も起動するので注意する。
