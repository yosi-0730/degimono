# ラズパイ在庫管理システム (Web画面プロトタイプ)

提供された画面イメージ（`image.png`）および『仕様書.md』に基づいて作成した、ラズパイ側 在庫管理システムのWeb画面です。

---

## 🚀 起動方法（仮想環境 `.venv` 使用）

仮想環境（`.venv`）をプロジェクト内に構築済みです。以下のいずれかの方法で簡単に起動・確認できます。

### 方法1: 起動スクリプトをダブルクリック（おすすめ）
- Windowsエクスプローラーで **`run.bat`** をダブルクリックして起動します。
- ブラウザで **`http://localhost:5000`** にアクセスします。

### 方法2: PowerShellから起動
```powershell
# 仮想環境を有効化して起動する場合
.\.venv\Scripts\Activate.ps1
python app.py

# またはスクリプトで直接起動
.\run.ps1
```

### 方法3: サーバーなしで画面だけ確認する場合
フォルダ内の **`index.html` をブラウザで直接ダブルクリック**するだけで、サーバーなしでもすべてのUI操作（検索・マップ切替・入出庫・CSV出力・発注警告）が動作します。

## 🎨 画面構成（`image.png` の完全再現 ＋ 入出庫共通化）

### 1. 全体レイアウト
- **黄色フレーム背景**: ワイヤーフレーム通りの鮮やかな黄色フレームと黒枠線。
- **右上ボタン**: 「入出庫履歴.csv出力」（クリックで文字化け防止BOM付きCSVダウンロード）。

### 2. 左側：部品検索 ＆ マップ
- **部品検索バー**:
  - `品名・品番入力、QR読み取り` 入力フィールド
  - 水色の `検索` ボタン
  - 下部にダミー部品（AB-1234, CD-5678, EF-9012, GH-3456, JK-7890）のクイック切替チップを配置
- **マップ表示エリア**:
  - `image.png` 通りに、白枠の中央に「マップ」と書かれたシンプルなプレースホルダー枠として表示
- **★ 部署・ソートされた従業員の連動プルダウン**:
  - 部署（製造部、開発部、資材課、品質管理部、設備保全課）を選択すると、その部署に所属する従業員が**五十音順に自動ソート**されて従業員プルダウンに反映されます。
- **★ 入出庫の共通化エリア**:
  - 入庫と出庫で分かれていたUIを1つに統合！
  - **[ 📥 入庫 (＋) ]** と **[ 📤 出庫 (−) ]** をワンタッチで切替可能
  - 数量は `[−] [ 1 ] [＋]` で直感的に増減
  - 部署・担当者を選択し、**「入庫する」/「出庫する」** ボタンを押すだけで、共通のデータ処理（在庫加算/減算、履歴追加、発注状態更新）を実行
- **発注警告バナー（赤色）**:
  - 在庫が発注点以下の部品（`AB-1234` 等）で **「発注してください！」** を大きく赤色で表示
  - バナーをクリックすると「発注済」にステータスが切り替わり、警告が自動解除されます（仕様書要件）

### 4. 下部：入出庫履歴ログ（折りたたみ式）
- 画面デザインをシンプルに保つため、下部に折りたたみ式で直近の入出庫ログを表示できるようにしています。
